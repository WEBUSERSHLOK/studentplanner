1. Factor and then simplify the answer completely. Express the answer as a fraction without negative exponents.

a. $2x(x+3)^{-1/2} + 4(x+3)^{1/2}$

b. $3(2x-1)^2(x+4)^4 + 8(2x-1)^3(x+4)^3$

c. $x^{-2} - 9y^{-2}$

d. $\frac{1}{2}(x^2+1)^{-1/2}(2x)(x-2)^3 + 3(x^2+1)^{1/2}(x-2)^2$

e. $2x^{-1/3} - x^{2/3}$

f. $(x^2-4)^{-1/2} - x(x^2-4)^{-3/2}$

g. $4x^3(3x-2)^3 + 9x^4(3x-2)^2$

h. $\frac{3(x+1)^{1/2} - \frac{3}{2}x(x+1)^{-1/2}}{x+1}$

Step-by-Step Solutions (1):

  • a. Factor out $2(x+3)^{-1/2}$: $2(x+3)^{-1/2}[x + 2(x+3)] = \frac{2(3x+6)}{\sqrt{x+3}} = \mathbf{\frac{6(x+2)}{\sqrt{x+3}}}$.
  • b. Factor $(2x-1)^2(x+4)^3$: $(2x-1)^2(x+4)^3[3(x+4) + 8(2x-1)] = \mathbf{(2x-1)^2(x+4)^3(19x+4)}$.
  • c. Express with positive exponents: $\frac{1}{x^2} - \frac{9}{y^2} = \mathbf{\frac{y^2-9x^2}{x^2y^2}} = \frac{(y-3x)(y+3x)}{x^2y^2}$.
  • d. $(x-2)^2(x^2+1)^{-1/2}[x(x-2) + 3(x^2+1)] = \mathbf{\frac{(x-2)^2(4x^2-2x+3)}{\sqrt{x^2+1}}}$.
  • e. Factor $x^{-1/3}$: $x^{-1/3}(2 - x) = \mathbf{\frac{2-x}{x^{1/3}}}$.
  • f. Common denominator $(x^2-4)^{3/2}$: $\frac{(x^2-4) - x}{(x^2-4)^{3/2}} = \mathbf{\frac{x^2-x-4}{(x^2-4)^{3/2}}}$.
  • g. Factor $x^3(3x-2)^2$: $x^3(3x-2)^2[4(3x-2) + 9x] = \mathbf{x^3(3x-2)^2(21x-8)}$.
  • h. Factor $\frac{3}{2}(x+1)^{-1/2}$ in numerator: $\frac{\frac{3}{2}(x+1)^{-1/2}[2(x+1)-x]}{x+1} = \mathbf{\frac{3(x+2)}{2(x+1)^{3/2}}}$.

2. Express as a simple fraction (simplify complex fractions).

a. $\dfrac{\frac{1}{x+2} - \frac{1}{2}}{x}$

b. $\dfrac{\frac{x}{y} - \frac{y}{x}}{\frac{1}{x} + \frac{1}{y}}$

c. $\dfrac{\frac{2}{(x+h)^2} - \frac{2}{x^2}}{h}$

Step-by-Step Solutions (2):

  • a. Multiply top & bottom by $2(x+2)$: $\frac{2-(x+2)}{2x(x+2)} = \frac{-x}{2x(x+2)} = \mathbf{-\frac{1}{2(x+2)}}$.
  • b. Multiply top & bottom by $xy$: $\frac{x^2-y^2}{y+x} = \frac{(x-y)(x+y)}{x+y} = \mathbf{x - y}$.
  • c. Top: $\frac{2[x^2 - (x+h)^2]}{x^2(x+h)^2} = \frac{2(-2xh-h^2)}{x^2(x+h)^2} = \frac{-2h(2x+h)}{x^2(x+h)^2}$. Divide by $h$: $\mathbf{-\frac{2(2x+h)}{x^2(x+h)^2}}$.

3. Find the following if $$f(x) = \begin{cases} 3 - 2x, & x < 1 \\ 4, & 1 \le x < 4 \\ x^2 - 3x, & x \ge 4 \end{cases}$$

a. $f(2)$
b. $f(0)$
c. $f(5)$
d. $f(4)$

Solutions (3):

a. $1 \le 2 < 4 \implies f(2) = \mathbf{4}$ • b. $0 < 1 \implies f(0) = 3 - 2(0) = \mathbf{3}$ • c. $5 \ge 4 \implies f(5) = 5^2 - 3(5) = \mathbf{10}$ • d. $4 \ge 4 \implies f(4) = 4^2 - 3(4) = \mathbf{4}$.

4. Multiply and expand: $(2\sqrt{x} - 3)(3\sqrt{x} + 5)$

Solution: FOIL: $6x + 10\sqrt{x} - 9\sqrt{x} - 15 = \mathbf{6x + \sqrt{x} - 15}$.

Linear Models (Point-Slope Form: $y - y_1 = m(x - x_1)$)

5. Passing through $(4, -2)$ with slope $m = -\frac{3}{4}$. Put in point-slope form.

$y - (-2) = -\frac{3}{4}(x - 4) \implies \mathbf{y + 2 = -\frac{3}{4}(x - 4)}$

6. Passes through $(3, 5)$ and is parallel to line $4x - 2y = 7$. Put in point-slope form.

$2y = 4x - 7 \implies y = 2x - 3.5 \implies m = 2$.
Line: $\mathbf{y - 5 = 2(x - 3)}$

7. Passes through $(-2, 6)$ and is perpendicular to line $3x + 5y = 10$. Put in point-slope form.

$5y = -3x + 10 \implies m_1 = -3/5 \implies m_\perp = \frac{5}{3}$.
Line: $\mathbf{y - 6 = \frac{5}{3}(x + 2)}$

8. Solve for $y'$ (Implicit Derivative Algebra isolation).

a. $3x^2 + 2x y' + 2y - 5y' = 0$

b. $x^2 y' + 2xy = 4y^2 y' - 3$

a. $y'(2x - 5) = -3x^2 - 2y \implies \mathbf{y' = \frac{-3x^2-2y}{2x-5} = \frac{3x^2+2y}{5-2x}}$.

b. $x^2 y' - 4y^2 y' = -2xy - 3 \implies y'(x^2-4y^2) = -(2xy+3) \implies \mathbf{y' = \frac{2xy+3}{4y^2-x^2}}$.

9. Find the domain of $f$ in interval notation.

a. $f(x) = \dfrac{\sqrt{16-x^2}}{2x-6}$

b. $f(x) = \ln(x^2 - 2x - 15)$

a. Need $16-x^2 \ge 0 \implies x \in [-4, 4]$. Denominator $2x-6 \ne 0 \implies x \ne 3$. Domain: $\mathbf{[-4, 3) \cup (3, 4]}$.

b. Need $x^2-2x-15 > 0 \implies (x-5)(x+3) > 0$. Domain: $\mathbf{(-\infty, -3) \cup (5, \infty)}$.

10. Solve for $x$:

$\dfrac{x}{x-2} + \dfrac{1}{x-4} = \dfrac{2}{x^2-6x+8}$

Factored denominator: $(x-2)(x-4)$. Multiply through:
$x(x-4) + 1(x-2) = 2 \implies x^2 - 4x + x - 2 = 2 \implies x^2 - 3x - 4 = 0 \implies (x-4)(x+1) = 0$.
Since $x = 4$ creates division by zero (extraneous), the only valid solution is $\mathbf{x = -1}$.

11. Find the $x$- and $y$-intercepts:

a. $y = x\sqrt{25 - x^2}$   b. $y = \dfrac{x^2 - 9}{x^2 + 4}$

a. $y$-int: $(0,0)$. $x$-int: $x\sqrt{25-x^2}=0 \implies \mathbf{x = 0, \pm 5}$ or points $\mathbf{(0,0), (5,0), (-5,0)}$.

b. $y$-int ($x=0$): $\mathbf{(0, -9/4)}$. $x$-int ($y=0$): $x^2-9=0 \implies \mathbf{(3, 0), (-3, 0)}$.

12. Find all points of intersection:

$\begin{cases} y = x^2 - 3x + 2 \\ y = 2x - 4 \end{cases}$

Set equal: $x^2 - 3x + 2 = 2x - 4 \implies x^2 - 5x + 6 = 0 \implies (x-2)(x-3) = 0 \implies x = 2, 3$.
If $x = 2$, $y = 2(2)-4 = 0 \implies \mathbf{(2, 0)}$.
If $x = 3$, $y = 2(3)-4 = 2 \implies \mathbf{(3, 2)}$.

13. Find the difference quotient: $\dfrac{f(x+h)-f(x)}{h}$

a. $f(x) = 2x^2 - 5x + 1$

b. $f(x) = \dfrac{1}{x+3}$

a. $\frac{2(x+h)^2 - 5(x+h) + 1 - (2x^2-5x+1)}{h} = \frac{4xh + 2h^2 - 5h}{h} = \mathbf{4x + 2h - 5}$.

b. $\frac{\frac{1}{x+h+3} - \frac{1}{x+3}}{h} = \frac{(x+3)-(x+h+3)}{h(x+h+3)(x+3)} = \mathbf{-\frac{1}{(x+h+3)(x+3)}}$.

14. Composition of Functions:

If $f(x) = \sqrt{x+7}$ and $g(x) = 2x^2 - 3$, find $(f \circ g)(x)$ and $(g \circ f)(x)$ with simplified expressions.

$(f \circ g)(x) = f(g(x)) = \sqrt{(2x^2 - 3) + 7} = \mathbf{\sqrt{2x^2 + 4}}$.

$(g \circ f)(x) = g(f(x)) = 2(\sqrt{x+7})^2 - 3 = 2(x+7) - 3 = \mathbf{2x + 11}$ (for $x \ge -7$).

15. Solve for $x$ exactly:

a. $e^{2x} - 4e^x - 5 = 0$

b. $\ln(x+2) + \ln(x-1) = \ln(10)$

c. $3^{2x-1} = 27^{x+2}$

d. $|3x - 5| = 2x + 7$

  • a. Let $u = e^x$: $u^2 - 4u - 5 = (u-5)(u+1) = 0 \implies u = 5$ (since $e^x > 0 \ne -1$). Thus $\mathbf{x = \ln(5)}$.
  • b. $\ln[(x+2)(x-1)] = \ln(10) \implies x^2 + x - 2 = 10 \implies x^2 + x - 12 = 0 \implies (x+4)(x-3) = 0$. Since $x > 1$, $\mathbf{x = 3}$.
  • c. $3^{2x-1} = (3^3)^{x+2} = 3^{3x+6} \implies 2x - 1 = 3x + 6 \implies \mathbf{x = -7}$.
  • d. Case 1: $3x-5 = 2x+7 \implies x = 12$. Case 2: $3x-5 = -(2x+7) \implies 5x = -2 \implies x = -2/5$. Both check in the original equation: $\mathbf{x = 12, -\frac{2}{5}}$.

Rational Functions: Discontinuities & Asymptotes

16. Indicate the points of discontinuity. Classify each as a vertical asymptote or a removable hole:

A) $f(x) = \dfrac{x^2-16}{x^2+2x-8}$
B) $g(x) = \dfrac{x+3}{x^2-9}$
C) $h(x) = \dfrac{x^2+1}{x-2}$

A: $\frac{(x-4)(x+4)}{(x+4)(x-2)}$. Hole at $x = -4$ (coordinates $(-4, 4/3)$); Vertical Asymptote at $x = 2$.

B: $\frac{x+3}{(x+3)(x-3)}$. Hole at $x = -3$ (coordinates $(-3, -1/6)$); Vertical Asymptote at $x = 3$.

C: Vertical Asymptote at $x = 2$; No holes.

17. Indicate where all asymptotes are — both Vertical and Horizontal (or slant if applicable):

A) $f(x) = \dfrac{3x^2 - 5}{2x^2 + 7x - 4}$
B) $g(x) = \dfrac{5x - 1}{x^2 - 4}$
C) $h(x) = \dfrac{2x^2 + 1}{x - 3}$

A: Denom: $(2x-1)(x+4)=0 \implies$ Vertical Asymptotes: $x = 1/2, x = -4$. Horizontal Asymptote: $y = 3/2$.

B: Vertical Asymptotes: $x = 2, x = -2$. Horizontal Asymptote: $y = 0$ (degree num < degree den).

C: Vertical Asymptote: $x = 3$. No Horizontal Asymptote; Slant Asymptote: $y = 2x + 6$.

18. Use the properties of logarithms to expand the expression completely:

a. $\ln\left(\dfrac{x^3 \sqrt{x-2}}{(2x+5)^4}\right)$

b. $\log_5\left(\dfrac{25 x^4}{\sqrt[3]{y^2+1}}\right)$

Trigonometry & Identities

19. If $\cos\theta = -\frac{5}{13}$ and $\theta$ is in Quadrant II, find $\tan\theta$ and $\csc\theta$.

In QII: $x = -5, r = 13 \implies y = \sqrt{13^2 - (-5)^2} = 12$.
$\mathbf{\tan\theta = -\frac{12}{5}}$, $\mathbf{\csc\theta = \frac{13}{12}}$.

20. Simplify completely: $\dfrac{\cos x}{1 - \sin x} - \tan x$

$\frac{\cos x}{1-\sin x} - \frac{\sin x}{\cos x} = \frac{\cos^2 x - \sin x(1-\sin x)}{\cos x(1-\sin x)} = \frac{\cos^2 x - \sin x + \sin^2 x}{\cos x(1-\sin x)} = \frac{1 - \sin x}{\cos x(1-\sin x)} = \frac{1}{\cos x} = \mathbf{\sec x}$.

21. Find $\sin(2\theta)$ if $\sin\theta = \frac{3}{5}$ and $\theta \in \left[0, \frac{\pi}{2}\right]$.

$\cos\theta = \sqrt{1 - (3/5)^2} = \frac{4}{5}$.
$\sin(2\theta) = 2\sin\theta\cos\theta = 2\left(\frac{3}{5}\right)\left(\frac{4}{5}\right) = \mathbf{\frac{24}{25}}$.

22. Write in algebraic form: $\sec(\arctan(2x))$

Let $\alpha = \arctan(2x) \implies \tan\alpha = \frac{2x}{1} = \frac{\text{opp}}{\text{adj}}$.
Hypotenuse $= \sqrt{1 + (2x)^2} = \sqrt{1 + 4x^2}$.
$\sec\alpha = \frac{\text{hyp}}{\text{adj}} = \mathbf{\sqrt{1 + 4x^2}}$.

26. Find two exact radian solutions in $[0, 2\pi)$ without a calculator:

b. $\cos\theta = \dfrac{\sqrt{2}}{2}$

27. Solve the equation for $\theta \in [0, 2\pi)$:

a. $2\sin^2\theta - \sin\theta - 1 = 0$
b. $2\cos^2\theta + 3\cos\theta + 1 = 0$
c. $\sin(2\theta) - \cos\theta = 0$
d. $\tan^2\theta - 3 = 0$

a. $(2\sin\theta+1)(\sin\theta-1) = 0 \implies \sin\theta = 1 \implies \mathbf{\frac{\pi}{2}}$ or $\sin\theta = -1/2 \implies \mathbf{\frac{7\pi}{6}, \frac{11\pi}{6}}$.

b. $(2\cos\theta+1)(\cos\theta+1)=0 \implies \cos\theta = -1/2 \implies \mathbf{\frac{2\pi}{3}, \frac{4\pi}{3}}$ or $\cos\theta = -1 \implies \mathbf{\pi}$.

c. $2\sin\theta\cos\theta - \cos\theta = 0 \implies \cos\theta(2\sin\theta-1) = 0 \implies \cos\theta = 0 \implies \mathbf{\frac{\pi}{2}, \frac{3\pi}{2}}$ or $\sin\theta = 1/2 \implies \mathbf{\frac{\pi}{6}, \frac{5\pi}{6}}$.

d. $\tan^2\theta = 3 \implies \tan\theta = \pm\sqrt{3} \implies \mathbf{\frac{\pi}{3}, \frac{2\pi}{3}, \frac{4\pi}{3}, \frac{5\pi}{3}}$.

28. Find all real zeros of the function:

a. $f(x) = 2x^3 - 3x^2 - 8x + 12$

b. $f(x) = \dfrac{x^3 - 4x}{x^2 - 1}$

b. Set numerator to $0$: $x(x^2-4) = x(x-2)(x+2) = 0 \implies x = 0, \pm 2$. None make the denominator zero. Zeros: $\mathbf{x = 0, 2, -2}$.

29. Graph Rational Functions

Identify Domain, Holes, Vertical & Horizontal Asymptotes, and Intercepts before graphing each curve on the grid.

A) $f(x) = \dfrac{2x - 4}{x + 1}$

V.A.: $x = -1$ • H.A.: $y = 2$

$x$-int: $(2, 0)$ • $y$-int: $(0, -4)$

Holes: None

B) $g(x) = \dfrac{x^2 - 1}{x^2 - 4}$

V.A.: $x = \pm 2$ • H.A.: $y = 1$

$x$-int: $(\pm 1, 0)$ • $y$-int: $(0, 1/4)$

Symmetry: Even (symmetric to $y$-axis)

C) $h(x) = \dfrac{x^2 - 2x - 3}{x - 3}$

Hole: $(3, 4)$ (removable discontinuity)

Simplified: Line $y = x + 1$ with hole at $x = 3$

$x$-int: $(-1, 0)$ • $y$-int: $(0, 1)$

Graph Analysis Details (29):

  • A: Domain $\mathbb{R} \setminus \{-1\}$. Vertical asymptote at $x = -1$. Horizontal asymptote at $y = 2$. Crosses the $x$-axis at $(2,0)$ and $y$-axis at $(0, -4)$. As $x \to -1^+$, $f(x) \to -\infty$; as $x \to -1^-$, $f(x) \to +\infty$.
  • B: Domain $\mathbb{R} \setminus \{-2, 2\}$. Vertical asymptotes at $x = -2$ and $x = 2$. Horizontal asymptote at $y = 1$. The central branch is an upward-opening curve passing through $(0, 1/4)$ and $(\pm 1, 0)$ tending towards $-\infty$ at both asymptotes. Outer branches lie above $y = 1$.
  • C: $\frac{(x-3)(x+1)}{x-3} = x+1$ for all $x \ne 3$. This is a linear function with slope $1$ and $y$-intercept $(0,1)$, featuring an open circle (hole) at $(3, 4)$. No asymptotes exist.
